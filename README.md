# Money and Points Management System

This project implements a simple **Money and Points Management System** that allows user registration, deposits, payments, sending money, and tracking spending history. It simulates real-time transactions and points redemption based on a given percentage rate. The system is designed to handle user balance and point management efficiently.

## Features
- **User Registration**: Allows the creation of a new user.
- **Deposits**: Users can deposit money into their account.
- **Payments**: Users can make payments using both money and points. Points are redeemed based on a given percentage rate.
- **Send Money**: Users can send money to other users, ensuring both sender and receiver balances are updated.
- **Show Balance**: Display the current balance and points of a user.
- **Change Redemption Rate**: Allows updating the points redemption rate.
- **Show Spent History**: Displays the spending history of a user, including the amount spent and points earned.

## Tech Stack
- **C++**: The core language for implementing the system logic.
- **Data Structures**: Unordered maps, deques, and maps to store and manage user data efficiently.
